# cdsize

cdsize показывает, сколько места занимает каждая таблица в файловой базе 1С `1Cv8.1CD`. Это программа только для чтения: файл отображается в память и не изменяется. Платформа 1С не нужна.

Версия 0.2.1. Язык — Python 3.10 и новее, у самой программы нет сторонних зависимостей. Имена вроде `_Reference7` — имена хранения, а не синонимы конфигуратора.

## Запуск

```bash
python3 -m cdsize путь/к/1Cv8.1CD
python3 -m cdsize путь/к/каталогу/базы
```

Если указан каталог, внутри берётся `1Cv8.1CD`. Команды `python` в инструкциях нет: везде `python3`.

Без пути открывается локальное окно в браузере. `--sort` сам по себе отчёт не включает. Отчёт без пути завершается с ошибкой. `FormatError` и `OSError` завершают процесс с кодом 2.

```bash
python3 -m cdsize --version
python3 -m cdsize база/1Cv8.1CD --json
python3 -m cdsize база/1Cv8.1CD --html --sort name --match _Reference --limit 20
python3 -m cdsize база/1Cv8.1CD --no-records
python3 -m cdsize --app --no-browser --port 47321
```

Сортировка: `size` (по умолчанию), `name`, `records`.

## Колонки

| Колонка | Смысл |
| --- | --- |
| таблица | Имя хранения |
| назначение | По префиксу: `_Reference` — справочник, `_vt` — табличная часть, `_AccumRg` — регистр накопления, `_AccumRgT` — итоги. Служебные `CONFIG`, `PARAMS`, `V8USERS`, `IBVERSION`, `DBSCHEMA`, `FILES` подписаны отдельно |
| занято | Строки, у которых первый байт не равен признаку свободной записи. Нулевая служебная строка не входит |
| всего | Все слоты, включая свободные и служебную строку: длина потока, делённая на длину записи |
| данные, BLOB, индексы | Длины потоков. BLOB — строки и двоичные поля неограниченной длины |
| поток | Сумма трёх длин |
| на диске | Страницы заголовка объекта, таблицы размещения и данных. Из-за размера страницы это больше длины потока |

«Свободно» в шапке — свободные страницы файла, а не сумма удалённых строк.

`ПолучитьРазмерДанныхБазыДанных()` (платформа 8.3.15+) сюда не относится: платформа суммирует `DATALENGTH` полей и не включает индексы, историю, расширения и служебные таблицы.

Неизвестный тип поля не мешает показать размеры потоков: число записей в такой таблице не считается. Ошибка схемы одной таблицы становится предупреждением, файл целиком из-за неё не отбрасывается.

## Окно

Без пути или с `--app` поднимается страница на `127.0.0.1:47321`. Если порт занят, пробуются следующие 10 портов. Слушается только loopback. `--no-browser` не открывает браузер, `--port` задаёт порт. Начальный путь можно передать аргументом и как `?open=`.

Интерфейс — одна страница `cdsize/ui.html`, без CDN: фильтр, сортировка по колонкам, карточки, обзор каталога, выгрузка HTML, JSON и текста. У замороженной сборки страница читается из `_MEIPASS`.

Кнопка «Обзор» не подменяет выбранный файл каталогом. Обзор файла вызывает `browse(path, false)`. Переход по папкам и закладкам вызывает `browse(path, true)`.

`CDSIZE_HOME` задаёт папку программы. Туда пишется `адрес.txt`. В закладках: домашний каталог, папка программы, `examples`, диски Windows или `/`. Скрытые файлы не показываются. Помечаются `.1cd` и каталоги, где есть `1Cv8.1CD`.

## Сборка портативных архивов

```bash
python3 packaging/build_portable.py
```

Скрипт заново собирает оба архива в `portable/` и удаляет `portable/work`.

- Linux: PyInstaller 6, один файл `cdsize`. В корне архива: `cdsize`, `ПРОЧТИ.txt`, `examples/`.
- Windows: официальный embeddable CPython 3.12.10 amd64. В корне: `Запуск.vbs`, `cdsize.bat`, `ПРОЧТИ.txt`, `app/`, `examples/`, `python/`. Окно — браузер: у embeddable нет tkinter и `pythonw`. `Запуск.vbs` скрывает консоль. Windows-сборку здесь не запускают.

В каждый архив кладутся `examples/mini.1CD` и `ПРОЧТИ.txt`. Файлы лежат в корне архива. У каталогов отдельная запись с именем на `/`.

## Проверки

```bash
python3 -m unittest
```

Пример `examples/mini.1CD`: формат 8.3.8, страница 8192, локаль `ru_RU`, 22 страницы (176 КБ), свободно 2. Справочник `_Reference7` — 2/4, поток 868 Б, на диске 48 КБ. Регистр `_AccumRg3` — 20/21, поток 4.7 КБ, на диске 48 КБ. Итого занято 24, всего 29, поток 5.7 КБ, на диске 144 КБ.
